# Security Policy

## Supported version

Security fixes are provided for the latest Community Edition release.

## Reporting a vulnerability

Report vulnerabilities privately with the repository host's **Security → Report a vulnerability** feature. Do not open a public issue. Include affected version, impact, reproduction steps, and a minimal proof of concept. Remove credentials, personal content, private addresses, and production data.

If private vulnerability reporting is unavailable, contact the repository owner through their public profile without including vulnerability details and request a secure reporting channel.

We will acknowledge actionable reports when possible, coordinate remediation, and credit reporters who request it. Do not access data you do not own or disrupt services while testing.
