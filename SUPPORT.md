# Community Support

Before opening an issue:

1. Use version `0.1.0` or the latest available snapshot.
2. Confirm Docker has enough memory and both database containers are healthy.
3. Confirm the configured inference endpoint is reachable from the app container.
4. Download a redacted diagnostic bundle from the Status page and inspect it yourself.

Use the matching issue category for installation/startup, migrations, local chat, image generation, Discord, Twitch/stream, or documentation. Include operating system, installation method, exact reproduction steps, expected/actual behavior, and the diagnostic bundle when safe.

Do not post API keys, tokens, prompts, conversation text, `.env` files, public service URLs, or unredacted logs. General community support is best effort. Requests outside the Community Edition boundary may be closed with an edition-boundary explanation.

Security vulnerabilities do not belong in public issues; follow [SECURITY.md](SECURITY.md).
